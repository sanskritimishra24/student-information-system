# Student Profile Hub

A responsive academic website project containing:
- Home page and navigation
- 3 individual student profile pages
- Images represented with profile avatars (replaceable with real images)
- Hyperlinks
- Ordered/unordered lists
- Academic tables
- Contact form
- Responsive CSS
- JavaScript validation
- Ready for free static hosting

## Run locally
Open `index.html` in a browser.

## Free deployment: GitHub Pages
1. Create a GitHub account and a new public repository.
2. Upload all project files, keeping the folder structure.
3. Open Settings -> Pages.
4. Under Build and deployment, select "Deploy from a branch".
5. Select the main branch and `/root`.
6. Save.
7. GitHub will provide a free `github.io` subdomain.

Replace the sample student information with your actual team/member details before submission.
